# Design plan

Color:
- bg: #0f1117 (same as app dark bg)
- surface: #1c1d21
- accent: #4cc9f0 (app teal)
- text: #e8e8ec
- text-dim: #7b7d8a
- white: #ffffff

Type:
- Inter throughout (Google Fonts)
- Display: 600 weight, tight tracking
- Body: 400, relaxed

Layout:
- Full-width dark hero with real app screenshot
- Features: 3-column grid
- Screenshots: horizontal scroll or grid
- Pricing: centered, minimal
- Footer: single line

Key principle: the app screenshot does the selling.
The copy just names what you're seeing.
